# unidocu F8·F9 단축키 맞춤 (크롬 확장)

unidocu 솔루션 버전마다 다른 펑션키(F8·F9) 배치를 **내가 원하는 배치로** 맞추는 크롬 확장 프로그램.
unidocu 플러그인 `functionKeySwap`(고객사 config 기준)과 같은 동작을 **사용자 브라우저 기준**으로 제공한다.
여러 고객사·버전을 오가는 개발자가 어디서든 같은 손 감각으로 키를 쓰는 용도.

| 솔루션 | F8 | F9 |
|---|---|---|
| A | 디버그 모드 | 테스트 |
| B | 조회 | 디버그 모드 |

## 설치 (압축해제된 확장 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택

## 사용

1. 팝업 맨 위 **내 디버그 키**를 고른다 (기본 F8)
2. unidocu 사이트에서 확장 아이콘 클릭 → **이 사이트에서 사용** 체크 → 권한 창에서 허용 (그 사이트 권한만 요청)
   - 처음 허용할 때 권한 창 때문에 팝업이 닫혀도, 허용하면 스크립트 등록 후 그 사이트 탭이 자동으로 새로고침된다.
3. 모드
   - **자동 감지 (기본)**: 페이지의 디버그 키를 감지해 내 설정과 다르면 F8↔F9 를 맞바꾸고, 같으면 그대로 둔다.
     같은 주소(예: localhost)에서 신규·기존 버전을 번갈아 띄워도 페이지마다 알아서 판단한다.
   - **직접 지정**: `F8=F9, F9=F8` 형식으로 매핑을 직접 입력 (감지가 안 되는 버전용)
4. 팝업에 감지 결과가 표시된다. 예) `감지: 이 페이지 디버그 = F9 → F8↔F9 맞바꿈`
5. **사용 중인 사이트** 목록에서 켠 사이트·모드 확인, [삭제]로 끄기

## 자동 감지 원리

코어 단축키 핸들러(`$(document).keydown`)의 소스에서 `$debug.onF8KeyDown()` 을 부르는 키 코드를 찾는다.
압축(minify)돼도 전역·속성 이름(`$debug.onF8KeyDown`)과 숫자(`120`)는 바뀌지 않아 같은 규칙으로 찾힌다.

```
솔루션 A:  if (keycode === 119) { ... $debug.onF8KeyDown() }   → 디버그 = F8
솔루션 B:  120===t&&(...,$debug.onF8KeyDown())                  → 디버그 = F9 (압축본)
```

감지에 실패하면(난독화, 다른 구조 등) **아무것도 바꾸지 않는다.** 그 사이트는 직접 지정을 쓰면 된다.

## 구성

| 파일 | 역할 |
|---|---|
| `background.js` | 켠 사이트 목록대로 콘텐츠 스크립트 동적 등록(권한 받은 호스트만, 순차 처리), 첫 허용 시 탭 새로고침 |
| `bridge.js` | ISOLATED world. 설정(모드·매핑·내 디버그 키)을 `<html data-fkc-config>` 로 페이지에 전달 |
| `remap.js` | MAIN world. 디버그 키 감지, window 캡처 단계에서 매핑된 키를 막고 바꾼 키로 `jQuery(document).trigger('keydown')` |
| `popup.html/js` | 내 디버그 키, 사이트 켜기/끄기·모드, 감지 결과, 사용 중인 사이트 목록 |

- unidocu 페이지(`window.$u` 와 jQuery 가 있는 페이지)에서만 동작, 매핑에 없는 키·Ctrl/Alt/Shift/Meta 조합은 통과
- unidocu 플러그인 `functionKeySwap` 이 같이 설치돼 있어도 확장이 먼저 처리하고(`stopImmediatePropagation`) 중복 변환하지 않는다
- 디버그 팝업 등 같은 사이트의 새 창·iframe 에서도 동작
- 크롬 111 이상 (`world: "MAIN"` 콘텐츠 스크립트)
